# Quectel EP06 / EM06 / EC25 Series

![](../images/ep06.png)

The **Quectel EP06** (Mini PCIe) and **EM06** (M.2 Key-B 3042) are LTE Cat-6 modules based on the **Qualcomm MDM9607 / MDM9207** chipset. The **EC25** series is an LTE Cat-4 equivalent. These modules are widely deployed in industrial routers, open-source OpenWrt devices, and IoT gateways due to their simplicity and broad protocol support.

# Tech Specs

| Specification | Value |
| :--- | :--- |
| **Chipset** | Qualcomm MDM9607 / MDM9207 |
| **Form Factor** | Mini PCIe (EP06) / M.2 3042 (EM06) / LCC (EC25) |
| **LTE Category** | LTE Cat-6 (EP06/EM06: 300 Mbps DL) / Cat-4 (EC25: 150 Mbps DL) |
| **Carrier Aggregation** | 2CA Downlink (EP06/EM06) |
| **MIMO** | 2x2 MIMO |
| **Protocols Supported** | QMI (`qmi_wwan`), ECM, RNDIS, Serial (`option` / `qcserial`) |

# Model Variants & Form Factors

- **EP06-E / EP06-A**: Mini PCIe form factor (EMEA / APAC / NA).
- **EM06-E / EM06-A**: M.2 Key-B 3042 form factor.
- **EC25-E / EC25-G**: LTE Cat-4 Mini PCIe or LGA module.

# USB VID:PID & Driver Support

| Model | USB VID:PID | Default Driver |
| :--- | :--- | :--- |
| **EP06 / EM06** | `2c7c:0306` | `qmi_wwan` / `option` |
| **EC25** | `2c7c:0125` / `2c7c:0121` | `qmi_wwan` / `option` |

# OpenWrt Configuration

```text
# Enable QMI protocol mode:
AT+QCFG="usbnet",0

# Enable ECM protocol mode:
AT+QCFG="usbnet",1

# Save and reboot modem:
AT+CFUN=1,1
```
