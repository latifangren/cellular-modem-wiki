# Key Features of Sierra Wireless Modems
- **Dual Firmware Architecture**: Carrier MBN switching (AT&T, Verizon, Sprint, Generic).
- **USB Composition Switching**: Toggle between QMI (`qmi_wwan`), MBIM (`cdc_mbim`), and Direct Serial modes via `AT!USBCOMP`.
- **DIP / Generic Firmware Cross-Flashing**: Unlocking OEM Dell DW5811e modules to generic Sierra firmware.
