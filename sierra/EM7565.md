# Sierra AirPrime EM7565 / EM7511

![](./images/em7565.png)

The **Sierra Wireless AirPrime EM7565** (and FirstNet band B14 variant **EM7511**) is a high-speed LTE Cat-12 M.2 3042 module based on the **Qualcomm Snapdragon X12** (MDM9240) chipset. It supports up to 600 Mbps downlink and 3-Band Carrier Aggregation.

# Tech Specs

| Specification | Value |
| :--- | :--- |
| **Chipset** | Qualcomm MDM9240 (Snapdragon X12) |
| **Form Factor** | M.2 Key-B 3042 |
| **LTE Category** | LTE Cat-12 (600 Mbps Downlink / 150 Mbps Uplink) |
| **Carrier Aggregation** | 3CA Downlink, 2CA Uplink |
| **MIMO** | 2x2 / 4x4 MIMO |
| **Supported Bands (FDD)** | B1, B2, B3, B4, B5, B7, B8, B9, B12, B13, B14 (EM7511), B17, B18, B19, B20, B26, B28, B29, B30, B32, B66 |
| **Host Interface** | USB 3.0 / USB 2.0 |
| **Protocols Supported** | QMI (`qmi_wwan`), MBIM (`cdc_mbim`) |
| **Operating Voltage** | 3.135V ~ 4.4V (Typ 3.3V) |
