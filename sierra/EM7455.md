# Sierra AirPrime EM7455 / EM7430 / Dell DW5811e

![](./images/em7455.png)

The **Sierra Wireless AirPrime EM7455** (and Asian regional variant **EM7430**) is an LTE Cat-6 M.2 3042 module built on the **Qualcomm MDM9230** (SDX7) chipset. Rebranded by Dell as **DW5811e** and Lenovo as **ThinkPad EM7455**, it is a classic, highly reliable 4G modem widely supported across Linux and OpenWrt.

# AT Command Password Unlock

To run administrative configuration commands on Sierra modems, unlock privileges first:

```text
AT!ENTERCND="AEROPASS"
```

---

# USB Composition Switching (`AT!USBCOMP`)

Sierra modems support changing their USB mode via `AT!USBCOMP`:

```text
# Unlock command access
AT!ENTERCND="AEROPASS"

# Query current composition
AT!USBCOMP?

# Set USB composition to QMI + AT + NMEA (Mode 1, Config 1)
AT!USBCOMP=1,1,10D

# Reset modem to apply changes
AT!RESET
```

# Cross-Flashing OEM Firmware to Generic

Dell DW5811e modems can be flashed with Generic Sierra firmware using the Sierra `swiflash` utility or Linux `qmi-firmware-update`:

```bash
# Flash Generic firmware under Linux
qmi-firmware-update --update-qdl SWI9X30C_02.33.03.00_GENERIC_002.000_000.cwe SWI9X30C_02.33.03.00_GENERIC_002.000_000.nvu
```
