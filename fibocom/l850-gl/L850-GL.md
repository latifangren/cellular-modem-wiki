# Fibocom L850-GL / Dell DW5820e

![](../images/l850_gl.png)

The **Fibocom L850-GL** is an LTE Cat-9 M.2 3042 cellular module based on the **Intel XMM7360** modem platform. It is widely used in HP laptops (G5 generation and newer, e.g., ProBook 430/440/450 G5, EliteBook 830/840/850 G5), ThinkPads, and Dell laptops (as **DW5820e**).

# Tech Specs

| Specification | Value |
| :--- | :--- |
| **Chipset** | Intel XMM7360 |
| **Form Factor** | M.2 Key-B 3042 |
| **LTE Category** | LTE Cat-9 (450 Mbps Downlink / 50 Mbps Uplink) |
| **Carrier Aggregation** | 3CA / 2CA (Note: Specific FDD+TDD combinations may be limited) |
| **MIMO** | 2x2 MIMO |
| **Features** | Global band support, eSIM support |
| **Host Interface** | PCIe / USB 2.0 / USB 3.0 |
| **Protocols Supported** | MBIM (`cdc_mbim`), NCM (`cdc_ncm`) |
| **Operating Voltage** | 3.135V ~ 4.4V (Typ 3.3V) |

# Interface & Protocol Modes (MBIM / NCM)

The L850-GL runs reliably in **MBIM** or **NCM** mode on OpenWrt / ROOter:
- **MBIM Mode**: Driver `cdc_mbim`
- **NCM Mode**: Driver `cdc_ncm`

---

# Linux & OpenWrt Configuration

```bash
modprobe cdc_mbim
modprobe cdc_ncm
```

# AT Commands

| Function | Command |
| :--- | :--- |
| **Check Firmware Version** | `ATI` or `AT+GMR` |
| **Check SIM Status** | `AT+CPIN?` |
| **Check Signal Quality** | `AT+CSQ` |
| **Radio On** | `AT+CFUN=1` |
