# Fibocom L850-GL / Dell DW5820e / HP lt4220 / Foxconn T77W968

![](../images/l850_gl.png)

The **Fibocom L850-GL** is an LTE Cat-9 M.2 3042 cellular module based on the **Intel XMM7360** chipset. It is widely deployed across enterprise laptops (Dell, HP, Lenovo) under various OEM part numbers and is popular in custom 4G router builds.

# Interface & Protocol Modes

The L850-GL operates primarily in **MBIM** (Mobile Broadband Interface Model) mode over USB or PCIe.

- **USB MBIM Mode**: Detected as a USB network device using the Linux kernel driver `cdc_mbim`.
- **PCIe MBIM Mode**: On modern Lenovo/Dell laptops, it communicates via PCIe using `iosm` or `xmm7360-pci` drivers.
- **CDC-NCM / QMI**: Supported on specific OEM firmware variants.

# Linux & OpenWrt Configuration

### 1. Required Kernel Modules
Ensure the following kernel modules are loaded on OpenWrt / Linux:

```bash
modprobe cdc_mbim
modprobe cdc_wdm
modprobe option
```

### 2. Device Detection Check
Run `lsusb` to verify modem recognition:

```bash
lsusb -d 413c:81ba   # Dell DW5820e
lsusb -d 2c7c:08ec   # Generic Fibocom
```

### 3. OpenWrt Network Setup (`/etc/config/network`)
```ini
config interface 'wan_mbim'
	option proto 'mbim'
	option device '/dev/cdc-wdm0'
	option apn 'internet'
	option auth 'none'
	option pdptype 'ipv4v6'
```

# FCC Lock / Unlock Procedure

Many OEM versions (especially Dell and Lenovo variants) ship with **FCC Lock** enabled, preventing RF initialization on non-whitelisted hosts.

### Unlock Commands via AT Port (`/dev/ttyUSB0` or `mmcli`):

```bash
# Check radio status
AT+CFUN?

# Set modem to full functionality
AT+CFUN=1

# Query FCC state (if return +CFUN: 0 or low power, issue unlock)
AT@FCCAUTH?
```

*Note: ModemManager includes built-in FCC unlock scripts for Fibocom L850-GL.*

| **Check Network Registration** | `AT+CGREG?` / `AT+CEREG?` |
| **Set Radio On** | `AT+CFUN=1` |
| **Set Radio Off / Airplane** | `AT+CFUN=0` |
