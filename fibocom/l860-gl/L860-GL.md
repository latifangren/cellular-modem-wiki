# Fibocom L860-GL / L860-GL-16

![](../images/l860_gl.png)

The **Fibocom L860-GL** (and **L860-GL-16**) is a Gigabit LTE Cat-16 M.2 3042 module powered by the **Intel XMM7560** modem chipset. Widely used in Lenovo ThinkPads and HP enterprise laptops.

# Tech Specs

| Specification | Value |
| :--- | :--- |
| **Chipset** | Intel XMM7560 |
| **Form Factor** | M.2 Key-B 3042 |
| **LTE Category** | Cat-16 (1 Gbps Downlink / 150 Mbps Uplink) |
| **Carrier Aggregation** | 5CA (5-Band Downlink CA), 2CA Uplink |
| **MIMO** | 4x4 MIMO |
| **Supported Bands (FDD)** | B1, B2, B3, B4, B5, B7, B8, B12, B13, B14, B17, B18, B19, B20, B21, B25, B26, B28, B29, B30, B32, B66 |
| **Supported Bands (TDD)** | B38, B39, B40, B41, B42, B43, B46 (LAA) |
| **Host Interface** | USB 3.0 / PCIe |
| **Default Protocol** | MBIM (`cdc_mbim`) |

# OEM VID:PID Reference

| Model / Branding | Manufacturer / OEM | USB VID:PID | Primary Protocol |
| :--- | :--- | :--- | :--- |
| **Fibocom L860-GL** | Generic Fibocom | `2c7c:08fd` / `08ec:08fd` | MBIM |
| **HP lt4210** | HP | `03f0:0a68` | MBIM |

*Note: Dell DW5821e is NOT a Fibocom L860-GL; Dell DW5821e is a Qualcomm Snapdragon X20-based Foxconn T77W968 card.*

---

# Protocol & Kernel Driver Support

The L860-GL operates in **MBIM** mode over USB 3.0 using the Linux kernel driver `cdc_mbim`.
