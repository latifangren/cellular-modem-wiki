# Fibocom L860-GL / L860-GL-16 / Dell DW5821e / Foxconn T77W968-16

![](../images/l860_gl.png)

The **Fibocom L860-GL** (and upgraded **L860-GL-16**) is a high-speed Gigabit LTE Cat-16 M.2 3042 module powered by the **Intel XMM7560** modem chipset. Rebranded by Dell as the **DW5821e**, it is widely used in high-performance laptops and OpenWrt router setups.

# Protocol & Kernel Driver Support

The L860-GL operates in **MBIM** mode over USB 3.0 using the Linux kernel driver `cdc_mbim`.

### Required Kernel Modules:
- `cdc_mbim`
- `cdc_wdm`
- `usbnet`

```bash
modprobe cdc_mbim
```

# OpenWrt Setup & `usb_modeswitch` Collision Fix

On OpenWrt, the Dell DW5821e (`413c:81d7`) can experience a reset loop caused by `usb_modeswitch` interfering with the MBIM interface.

### Symptom:
`dmesg` shows `wwan0: register 'cdc_mbim'` immediately followed by `wwan0: unregister 'cdc_mbim'`.

### Fix: Disable `usb_modeswitch` rule for `413c:81d7`:

Add the following exclusion to `/etc/config/usb_modeswitch` on OpenWrt:

```ini
config rule
	option vendor	0x413c
	option product	0x81d7
	option disable	1
```

Then restart services:
```bash
uci commit usb_modeswitch
/etc/init.d/usb_modeswitch restart
/etc/init.d/network restart
```
