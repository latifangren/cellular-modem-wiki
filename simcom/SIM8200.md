# SIMCom SIM8200EA-M2 / SIM8262E-M2 5G Modems

![](./images/sim8200.png)

The **SIMCom SIM8200EA-M2** (Snapdragon X55) and **SIM8262E-M2** (Snapdragon X62) are multi-band 5G NR Sub-6 and LTE Cat-16/20 M.2 modules. Popularly featured in Waveshare 5G HATs for Raspberry Pi and open-source OpenWrt routers.

# OpenWrt Driver (`qmi_wwan_simcom`) Setup

SIMCom 5G modules require the custom `qmi_wwan_simcom` kernel module for QMI multiplexing:

```bash
# Load option driver for AT serial commands
modprobe option

# Bind SIMCom VID:PID if needed
echo "1e0e 9001" > /sys/bus/usb-serial/drivers/option1/new_id
```

### Switch Protocol via AT Commands:
```text
# Switch to QMI mode:
AT+CUSBMODE=0

# Switch to RNDIS mode:
AT+CUSBMODE=1

# Reboot modem:
AT+CFUN=1,1
```

| **Check 5G Signal Quality** | `AT+CPSI?` |
