# Telit FN980 / FN980m / FN990A40 5G Modems

![](./images/fn980.png)

The **Telit FN980** (Snapdragon X55) and **Telit FN990** (Snapdragon X65) are industrial-grade 5G NR M.2 Key-B 3050/3052 modules supporting 5G Sub-6 and mmWave bands with Gigabit LTE fallback.

# Tech Specs

| :--- | :--- |
| **Chipset** | FN980: Qualcomm SDX55 / FN990: Qualcomm SDX65 |
| **Form Factor** | M.2 Key-B 3050 / 3052 |

# Linux & OpenWrt Configuration

Telit modems support native MBIM and QMI modes out of the box in Linux kernel 5.4+:

```bash
# Verify USB detection
lsusb -d 1c7a:0570

# OpenWrt Network Protocol (MBIM):
uci set network.wan_telit.proto='mbim'
uci set network.wan_telit.device='/dev/cdc-wdm0'
uci set network.wan_telit.apn='internet'
uci commit network
```

# AT Commands

| Function | Command |
| :--- | :--- |
| **Check Firmware Revision** | `ATI` |
| **Check Serving Cell & 5G Info** | `AT#RFMODE?` |
| **Check Signal (CSQ / RSRP)** | `AT+CSQ` / `AT+CESQ` |
| **Set Radio Mode** | `AT#WS46=30` (5G/4G Mode) |
