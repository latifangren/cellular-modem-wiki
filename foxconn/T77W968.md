# Foxconn T77W968 / Dell DW5821e

![](./images/t77w968.png)

The **Dell DW5821e** (Foxconn part number **T77W968**) is a high-speed Gigabit LTE Cat-16 M.2 3042 module powered by the **Qualcomm Snapdragon X20 LTE** (SDX20) modem platform (VID:PID `413c:81d7`). Widely deployed in Dell Latitude and Precision laptops and used in custom 4G router builds.

# Dell DW5821e vs Fibocom L860-GL Clarification

- **Dell DW5821e (Foxconn T77W968)**: Built on **Qualcomm Snapdragon X20**.
- **Fibocom L860-GL**: Built on **Intel XMM7560**.
*(Note: While both are LTE Cat-16 1Gbps M.2 cards, their internal SoC platforms and drivers differ).*

# OpenWrt `usb_modeswitch` Reset Loop Fix

On OpenWrt, `usb_modeswitch` can reset `413c:81d7`, causing `wwan0` to continuously register/unregister.

Add exclusion to `/etc/config/usb_modeswitch`:
```ini
config rule
	option vendor	0x413c
	option product	0x81d7
	option disable	1
```

Commit & restart:
```bash
uci commit usb_modeswitch
/etc/init.d/usb_modeswitch restart
```
