# Foxconn T99W175 / Dell DW5930e 5G Modem

![](./images/t99w175.png)

The **Foxconn T99W175** (rebranded by Dell as **DW5930e**) is a 5G NR Sub-6 and mmWave M.2 3042/3052 module based on the **Qualcomm Snapdragon X55** (SDX55) platform architecture (USB VID:PID `413c:81e8` / `413c:81e0` / `05c6:90d5`). Widely used in Dell enterprise laptops and custom OpenWrt router boards (such as Banana Pi BPI-R4).

# USB & PCIe Modes

### 1. USB Mode (`05c6:90d5`)
Used when connected via M.2 USB3.0 adapters:

```bash
echo "05c6 90d5" > /sys/bus/usb-serial/drivers/option1/new_id
```

### 2. PCIe Mode (`mhi_pci` / `mhi_net`)
Used when installed directly in an M.2 PCIe slot (e.g. BPI-R4). Communicates via Qualcomm MHI bus driver.
