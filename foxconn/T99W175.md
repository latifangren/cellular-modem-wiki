# Foxconn T99W175 / DW5930e 5G Modem

![](./images/t99w175.png)

The **Foxconn T99W175** is a high-performance 5G NR Sub-6 and mmWave M.2 3042/3052 module based on the **Qualcomm Snapdragon X55** (SDX55) platform architecture. Widely used in Dell enterprise laptops and custom OpenWrt router boards (like Banana Pi BPI-R4).

# USB & PCIe Modes

The T99W175 can operate in two distinct hardware modes:

### 1. USB Mode (VID:PID `05c6:90d5` / `0489:e0b4`)
Used when connected via M.2 to USB3.0 adapters or USB router ports. Requires adding VID:PID to the Linux `option` driver:

```bash
echo "05c6 90d5" > /sys/bus/usb-serial/drivers/option1/new_id
```

### 2. PCIe Mode (`mhi_pci` / `mhi_net`)
Used when installed directly in an M.2 PCIe slot (e.g. BPI-R4, x86 motherboards). Communicates via Qualcomm MHI bus driver.

# Linux & OpenWrt Integration

```bash
# Verify USB connection
lsusb -d 05c6:90d5
lsusb -d 0489:e0b4

# OpenWrt Network Protocol (MBIM):
uci set network.wan_5g.proto='mbim'
uci set network.wan_5g.device='/dev/cdc-wdm0'
uci set network.wan_5g.apn='internet'
uci commit network
```
