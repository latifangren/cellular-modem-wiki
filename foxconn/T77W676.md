# HP lt4220 / Foxconn T77W676 / Telit LN940

![](./images/lt4220.png)

The **HP lt4220** is an OEM cellular module manufactured by **Foxconn (T77W676)** and based on the **Telit LN940** hardware design. Powered by the **Qualcomm Snapdragon X12 LTE-A** chipset, it is a high-value M.2 3042 module widely modified for OpenWrt router setups.

# Tech Specs

| Specification | Value |
| :--- | :--- |
| **Chipset** | Qualcomm Snapdragon X12 LTE-A |
| **Form Factor** | M.2 Key-B 3042 |
| **Default LTE Category** | LTE Cat-9 (450 Mbps DL / 50 Mbps UL) |
| **Unlocked LTE Category** | LTE Cat-11 / Cat-12 (up to 600 Mbps DL with 256QAM) |
| **Carrier Aggregation** | Up to 3CA (3-Band Downlink CA) |
| **Modulation** | 256QAM Downlink / 64QAM Uplink |
| **Protocols Supported** | MBIM (`cdc_mbim`), QMI (`qmi_wwan`), Serial (`option`) |
| **HP Compatibility** | HP EliteBook x360 1030 G3, Elite x2 1030 G3, ZBook 14u/15u G5 |

# Cat-9 to Cat-12 Firmware Flash (600 Mbps 3CA)

Stock HP firmware locks the module to Cat-9 (450 Mbps). By flashing modified/generic Telit LN940 or unlocked firmware, the modem enables:
- **Cat-12 3CA** (3-band carrier aggregation).
- **256QAM** modulation support.
- Full MBIM and QMI dual-protocol selection on OpenWrt / ROOter.

# Protocols & OpenWrt Compatibility

Works out-of-the-box on OpenWrt and ROOter using:
- **MBIM**: `kmod-usb-net-cdc-mbim`
- **QMI**: `kmod-usb-net-qmi-wwan` + `qcserial` / `option`

```bash
# Verify USB ID
lsusb -d 03f0:9d1d   # HP lt4220
lsusb -d 105b:e0ab   # Foxconn T77W676
lsusb -d 1c7a:0570   # Telit LN940
```

# AT Commands

| Function | Command |
| :--- | :--- |
| **Check Firmware & Revision** | `ATI` |
| **Check Active CA (Carrier Aggregation)** | `AT!GSTATUS?` or `AT+QCAINFO` |
| **Check RSRP/RSRQ Signal** | `AT+CSQ` |
| **Radio On** | `AT+CFUN=1` |
